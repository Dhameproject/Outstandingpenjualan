Aturan yang dipakai

  • Satu NP dihitung satu kali (satu NP bisa berisi beberapa item).
  • Kirim / Amsen (Gudang Store: Delivery Indent Supplier, Delivery Indent Store/DC, Cash&Delivery via Gudang Store; dan Cash&Delivery via Another Site): dilihat dari kolom Comment. Jika ada kata AMSEN (contoh "AMSEN;" atau "INDEN SPL; AMSEN") = Amsen. Selain itu, termasuk comment kosong = Kirim.
  • Retail / Consi (Cash&Delivery via Supplier): item yang namanya diawali C/ = Consi. NP yang berisi item C/ dihitung Consi.
  • Kartu Outstanding NP by Month / by Store tidak memasukkan Cash&Carry (via PnD / Gudang Store).
  • Stok: dari file Stock Qty and Value (kolom Quantity), dicocokkan dengan Kode Store + No Item. Merah = stok lebih kecil dari qty outstanding; "Stok —" = item tidak ada di data stok.
  • Late = Promised Delivery Date sebelum tanggal report ditarik.
  • Baris yang Status NP-nya kosong (outstanding hanya di WMS) tetap dihitung, ditandai "Hanya di WMS".
